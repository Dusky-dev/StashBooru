# StashBooru 1.1.1

A small settings polish update on top of 1.1.

## Included

- **Settings descriptions.** The System and Interface groups now say what they
  contain, like the other Settings pages.
- **Security moved to System.** Username, password, API key and session length
  are now the *Security* group in Settings → System. Old Security links still
  open it.
- **Plainer log console.** The log console is a flat Linux-style console in the
  app's own colours, without the window buttons and glow.

## Before updating

Back up the database, configuration and media using the documented
fork-compatible procedure. Download the binary for your platform; SHA-256
checksums are included. Updates are not installed automatically.

## Scope and limitations

No database or configuration changes since 1.1.0. The limitations listed for
1.0 still apply.
