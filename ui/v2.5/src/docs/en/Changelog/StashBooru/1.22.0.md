- **Artist pictures moved to Set image.** While editing an Artist, **Set image** lists **From … profile picture** for each connected creator account. Choosing one loads the picture into the form; **Save** keeps it, like any other image. The Identities section no longer has its own picture buttons.
- **Pixiv profile pictures.** Connected Pixiv accounts (`user:123`) offer their profile picture too. This needs the Pixiv OAuth access token in the source's API key setting; accounts using Pixiv's default avatar have no picture to offer.
