- **Rule34 MD5 lookups keep tag types.** A Rule34 match now lists its Artist, Character, Copyright and meta tags as such instead of putting every tag in General. Rule34 searches ask the site for each post's tag types, and the MD5 lookup also uses an installed tag CSV, as the Booru browser does.
- **Path first in Image details.** The file's path now leads the file details.
- **Filename tokens are a setting.** What the tagging filename layout reads from a file name is off by default; turn on **Show what the filename layout reads** in Settings › Interface › Image titles. When shown, each name appears as its own chip under **From filename**.
- **Easier details panel controls.** Resizing the panel shows a thin line instead of highlighting the whole strip. **Hide details** is a button at the end of the Details / Edit tabs, and a **Details** button beside the Image brings the panel back.
