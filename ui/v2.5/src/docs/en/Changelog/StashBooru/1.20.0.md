- **New Booru preview keys.** **↑/↓** move the highlight through the media files, **←/→** change post, **E** downloads the highlighted file and **Q** ignores the post. Ignoring now moves straight to the next post, so the ignored one disappears at once.
- **One media file open at a time.** A post's files start collapsed except the first; moving the highlight (or clicking a row) opens that file and collapses the previous one. Collapsed rows load no preview.
- **Clearer highlight.** The highlighted file has a tinted background and an accent bar instead of a thin outline.
- **Convert toggle is an icon** next to **Download to…**: highlighted when downloads will be converted with Media converter defaults.
