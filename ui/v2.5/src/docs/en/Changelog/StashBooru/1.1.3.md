- **Pawchive creators by name.** Pawchive and Kemono creators now show their real name (for example "Voiderino's Hideout") instead of `creator:patreon:123`, so you can find them in Identities and in Artist searches. Names load in the background while you browse and appear the next time the post list loads.
- **Open creators in the Booru browser.** The site chip on a Pawchive, Kemono or Pixiv account now opens that creator's posts, just like it does for tags.
- **Identities checkbox fix.** Ticking or unticking a second row on the Identities page no longer crashes the page.
