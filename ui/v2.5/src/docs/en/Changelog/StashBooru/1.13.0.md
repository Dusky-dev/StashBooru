- **Characters match in either name order.** A suggested "Miku Hatsune" now finds your existing "Hatsune Miku", as long as only one Character has that name. In Image Tagging jobs, sources that disagree on the order count as one Character.
- **Duplicate Character warnings.** Image Tagging warns when the selection holds the same Character with the name reversed, or several Characters while the tags (`solo`, `1girl`, …) say the Image shows one person. Nothing is merged or deleted.
- **One-person Images in jobs.** When the tags say an Image shows one person but the models suggest several Characters, a job (and automatic tagging after a Booru download) skips those model Characters and logs it. Characters from the filename or an MD5 match are kept.
