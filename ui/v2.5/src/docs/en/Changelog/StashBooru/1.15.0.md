- **Sort and filter names say what they do.** On Images, **Similarity (pHash or EVA02)** replaces "Perceptual Similarity (pHash)", since Find similar can match by pHash or by related content (EVA02). On Videos it reads **Similarity (pHash)**. The pHash filter is **Perceptual Hash (pHash)**, and Video, Image and Gallery codes are labelled **Code** instead of "Artist Code".
- **Copyrights filter on Images and Videos.** The sidebar now has the Copyrights filter that All already had.
- Copyrights no longer list **Created At** and **Updated At** twice in Sort by.
- **Image and Video details list only their own Copyrights.** The details panel no longer adds every Copyright of each Character shown, such as a Character's other games or series. It shows the Copyrights set on the Image or Video and their parent Copyrights, matching filters and Copyright pages. Each Character card still lists that Character's own Copyrights.
