- **Choose the sites for MD5 lookup.** **Settings → Processing → Similarity and tagging** has a new **Sites for MD5 lookup** list. Image and Video Tagging look up an image's MD5 on the sites you tick, in their order. Any Booru browser source that can search by MD5 can be used, including e621, and sources with saved credentials use them. A match must have the exact MD5.
- **Save the post link.** When an MD5 lookup finds a post, Image and Video Tagging add the post's link to the media's URLs on Apply. Untick **Add the post link** to skip it.
