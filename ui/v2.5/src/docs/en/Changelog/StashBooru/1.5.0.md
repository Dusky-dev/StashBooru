- **Native StashBooru app for Android, Linux and Windows.** A separate app (not a web page in a wrapper) that connects to your server with its address and, if the server has a password, the API key from Settings → Security. Browse All, Images, Videos, Characters, Artists, Copyrights, Tags, Galleries and Collections. Search, sort, swipe through images with zoom, and play videos in the built-in player. It also connects to a regular Stash server, without All and Copyrights. It can't edit anything yet. Builds come from the *Native app* workflow; see `app/README.md`.
