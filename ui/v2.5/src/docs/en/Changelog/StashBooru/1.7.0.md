- **Images and Videos get a date.** New Booru downloads now fill in the Date: when the photo was taken (from the file's EXIF data, Images only), otherwise when it was posted on the site. A Date you already set is never changed.
- **Fill missing dates** (Settings → Tasks → Library) does the same for your existing library, using your saved Booru download records. Items with neither date keep using the date they were added.
- Because Dates are now filled in, sorting by Date and the "Recently Released" main-page rows change for these items.
