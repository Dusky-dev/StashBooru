- **Customize Image details.** The sliders button beside the Details / Edit tabs lets you remove any part of the details panel (title, tag sections, file rows and more) and bring it back later. The panel can be resized only while customizing.
- **Hide details stays in one place.** The button that hides the details panel now sits at the Image's top-left corner, where the **Details** button appears when the panel is hidden.
- **Media gallery in Booru previews.** A post with several media shows them as small thumbnails at the top of the preview; choose one to jump to it.
- **Q ignores the selected media.** In a post with several media, Q ignores only the selected one and moves to the next; ignoring the last one ignores the post. Posts with one media work as before.
- **Steadier preview keys.** Keyboard shortcuts keep working after moving to another post.
- **Convert is harder to switch off by accident.** The convert option is now a labelled switch on its own line, apart from the download buttons.
- **Upstream Stash updates.** Includes the new Verify and Purge missing tasks (replacing Clean), Image rating keys in the viewer and scraper URL conflict warnings.
