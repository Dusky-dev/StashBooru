- **Booru browser: collapsible ZIP archives.** A ZIP in a post now has a header you can click to collapse or expand its files.
- **Collapsible media in big posts.** A post with more than four media files gets a "N media files" header that collapses them all.
- **Keyboard selection in posts.** **Shift+↓** and **Shift+↑** move a highlighted selection through every media file, including files inside a ZIP, and load more as you go. **↑** downloads the highlighted file. **←/→** still browse posts and **↓** still ignores.
