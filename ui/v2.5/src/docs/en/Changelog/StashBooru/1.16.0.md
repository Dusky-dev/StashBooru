- **Connect Booru tags that have no category.** Sites such as Paheal send every tag without a category, so those tags could not be connected. In the Booru browser, such a tag now offers **Connect as Character**, **Connect as Artist** and **Connect as Copyright**. Once connected, the tag is listed in that section on every post from the site, and downloads link it to that Character, Artist or Copyright instead of creating a Tag. Images downloaded before you connect a tag keep it as a Tag.
