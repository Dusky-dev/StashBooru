- **Ignore Tags, Characters, Artists and Copyrights you don't want.** Tick **Ignored** on an edit page (also in the bulk edit dialogs for Tags, Characters and Artists). An ignored item is hidden from lists and selectors, and downloads, Image and Video Tagging, bulk tagging and Auto Tag never add or recreate it; tagging review doesn't suggest it. Use the **Ignored** filter on each list to find it again. Media that already has an ignored item keeps it.
