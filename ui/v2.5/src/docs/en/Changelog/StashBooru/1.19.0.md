- **Tagging a selection clears it.** After an Image Tagging job starts, or after you finish reviewing every selected item with at least one applied, the selection on Images, Videos and All is dismissed. Cancelling keeps it.
- **Filename tokens in Image details.** When an Image's filename matches the filename layout in tagging setup, the details list what each token read (`%artist%`, `%copyright%`, `%character%`, `%md5%`, `%ext%`), next to the MD5 checksum.
- **Resize or hide the Image details panel.** On wide screens, drag the edge between the panel and the Image (or focus it and use the arrow keys; double-click resets it). The arrow button, or the **,** key, hides and shows the panel; on phones it is **Hide details** below the Image. Both are remembered.
- Checksums, paths and URLs in Image details wrap instead of being cut off.
