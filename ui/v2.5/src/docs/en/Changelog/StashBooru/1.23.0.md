- **Twitter / X in the Booru browser.** A new **Twitter / X** source browses `@handle` or `user:123` (an account's posts with images or videos, without retweets and replies), `id:123` (one post) or words (a recent search; X only searches the last 7 days). Photos download at original size and videos as MP4; a post's images are its media files. It needs your own X API bearer token in the source's API key setting, and X API access is paid or credit-based.
- **X profile pictures.** A connected X account offers its profile picture under **Set image** while editing an Artist, like Pixiv, Pawchive and Kemono.
