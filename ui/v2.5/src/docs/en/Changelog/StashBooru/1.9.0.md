- **Review metadata is now Image Tagging** (Video Tagging for Videos).
- **Tag many Images at once from their filenames.** Select two or more Images and choose **Image Tagging…**. You can now apply local filename metadata to the whole selection in one confirmed job. This no longer needs the bulk model setting. Camie and EVA02 still need **Allow Camie and EVA02 to tag several selected Images in one job** in tagging setup.
- The tagging dialog now shows how many local filename items it found, instead of always saying "Local loaded".
