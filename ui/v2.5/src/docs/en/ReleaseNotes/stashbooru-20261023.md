StashBooru builds on Stash for Images, Videos and illustrated-media metadata.
Artists, Characters and Copyrights are native library records; Copyright means a
work, series or franchise.

- **Start with your library.** Add folders in Settings → Library, then scan them
  from Settings → Tasks. Browse Images and Videos together in **All**.
- **Connect source names.** Use **Sources & aliases** on a profile to connect
  different provider names to the same record. **Booru** browses remote posts and
  downloads them into the library. **Following** currently checks saved targets
  on Danbooru-compatible sources.
- **Configure optional processing.** Settings → Processing holds worker/model
  setup and defaults for metadata review, similarity, conversion and upscaling.
  Review predictions or file previews before applying changes.
- **Keep backups.** Database backups do not include media files, configuration or
  original-file restore caches. Back those up separately. StashBooru database
  backups require a compatible StashBooru version.

Read the [StashBooru feature guide](https://github.com/Dusky-dev/StashBooru/blob/develop/docs/features.md)
for current workflows and limits. Revisit this introduction in Settings →
Changelog, where upstream Stash release history also remains available.
